# Launch kit

Everything you need to run the BandConnect launch. Start with the plan, then
work the lists with the templates and tracker.

| File | What it's for |
| --- | --- |
| **[../GTM.md](../GTM.md)** | The go-to-market & launch plan — strategy, beachhead, phased timeline, metrics. **Read this first.** |
| **[ct-venues-and-supply.md](ct-venues-and-supply.md)** | Researched, sourced directory of CT venues, open mics, record stores & studios to onboard (supply). |
| **[distribution-and-communities.md](distribution-and-communities.md)** | Calendars to get listed on, press to pitch, subreddits/groups, colleges & partnerships (demand + distribution). |
| **[outreach-templates.md](outreach-templates.md)** | Copy-paste venue email, band DM, press pitch, Reddit/IG posts, weekly digest. |
| **[outreach-tracker.csv](outreach-tracker.csv)** | Lightweight CRM — track every venue/band/press/community touch and its status. |
| **[trust-and-verification.md](trust-and-verification.md)** | How to confirm a band/venue is really them (verification ladder, claim flow, Verified badge). |

**The one-paragraph version:** be the best *calendar* of CT shows first (seed
real events yourself so it's never empty), win **New Haven** before the whole
state, recruit a founding cohort of ~10 venues + ~25 artists, launch via the
cohort's own audiences + local Reddit + local press, then let the loops already
built (SEO rich results, share-to-friend, saved-search alerts, RSVP reminders)
compound. North Star: **weekly RSVPs**.

> ⚠️ The research lists mark unverified contacts as `verify` and **never invent
> emails/handles**. Confirm a booking/contact before you send, and respect each
> community's self-promotion rules.
